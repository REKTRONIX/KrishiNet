Model Based Reflex Agent for Precision Sustainable Agriculture.

This repository contains a TypeScript implementation of a model-based reflex agent for precision agriculture, a simple R simulation, and utility components used for visualization.

Live demo / AI Studio project

- Google AI Studio app: https://krishinet-precision-agro-agent.ai.studio

Quickstart

- Node 18+ recommended
- Install dependencies:

  npm install

- Run development server (if UI present):

  npm run dev

R simulation

Open `krishinet_agro_agent.R` in R or RStudio and run the `run_krishinet_simulation()` function to run a basic simulation.
